- 网络角色改用 SurvivalEngine 人物模型和 URP 材质；`FrameworkDemo` 去掉测试地面，大厅表现集中在 `LobbyPresentation`。

- 网络协议为 4，应用版本为 0.3.0；AOT 契约变动后已运行正式 HybridCLR Generate All 并重建 Windows Offline 客户端。

## 双机人工验收操作

1. 两台 Windows 电脑连同一私人局域网，复制**同一份** `Build/WindowsClient` 完整目录；不要混用旧版 0.2.0 客户端。房主电脑允许私人网络入站 UDP `7770`，不开放公网端口。
2. 房主打开 `HavenClient.exe`，在大厅的「服务器地址」保留 `127.0.0.1` 和端口 `7770`，点击「连接并创建房间」，记下六位房间码。客机打开同一构建，将「服务器地址」改为房主的局域网 IPv4，输入房间码，点击「连接并加入房间」。客机点「准备」，房主点「开始游戏」。
3. 两边核对各自能移动与点击移动，并观察人物模型、动画、相机、地面和材质；不得出现洋红材质、闪烁地面、重复摄像机或远端角色被本机操作。
4. 两人轮流采集同一棵树／同一块石头，核对竞争对象不会重复掉落；检查各自背包不互相显示。随后分别制作、装备、建造，核对材料只扣一次、建筑位置一致；再攻击敌人，核对伤害、死亡和掉落一致。
5. 向营地管事接取与交付委托，核对共享任务状态和奖励；客机不应打开房主专属的本地任务界面。尝试在联机暂停菜单保存、读档、新游戏，相关按钮应不可点击。退出房间后重新创建，再检查没有旧角色和背包残留。
6. 房主退出时核对客机断开与返回菜单。保存两边日志和实机画面，连续游玩至少十分钟后再把全流程标记为通过。

目前上述第 3–6 步没有双机实测证据，不能根据自动探针推定通过。
