# WP3 局域网联机使用说明

## 功能范围

当前“房间”是 FishNet Tugboat（UDP）的局域网 IP 直连会话，不包含账号、互联网匹配、云大厅和房间列表。房主与加入者需要处于可互通的局域网；跨公网使用需另行配置端口映射或中继服务。

## 统一配置

配置资产：`Assets/Resources/HavenNetworkSettings.asset`

| 配置 | 默认值 | 说明 |
|---|---:|---|
| 传输协议 | FishNet Tugboat（UDP） | 客户端与房主必须一致 |
| 监听端口 | 7770 | 防火墙需允许该 UDP 端口 |
| 最大人数 | 4 | 包含房主；超出后返回“房间人数已满” |
| 协议版本 | 3 | 不一致时在生成玩家前拒绝连接；版本 3 包含 WP4 合作玩法协议 |
| 连接超时 | 10 秒 | 超时后进入 Failed，可返回菜单重试 |
| 主菜单场景 | MainMenu | 退出房间后的目标场景 |
| 单人场景 | WorldGenMap | 单人模式目标场景 |
| 联机场景 | FrameworkDemo | 创建/加入房间使用的场景 |

## 创建房间

1. 启动游戏，点击“开始游戏 → 联机模式 → 创建房间”。
2. 本机启动 Host，并完成本地客户端的协议认证。
3. 进入联机场景后，左上角显示“房间地址”，格式为 `局域网IPv4:端口`。
4. 点击“复制房间地址”，通过可信渠道发送给同一局域网内的玩家。
5. 房主点击“退出房间并返回主菜单”时，同时停止本地客户端和房间服务器。

如果显示 `127.0.0.1`，说明未检测到可用的局域网 IPv4。请检查网卡连接，并通过 `ipconfig` 查询实际 IPv4 地址。

## 加入房间

1. 点击“开始游戏 → 联机模式”。
2. 在“服务器地址”中输入房主提供的 `IP:端口`；省略端口时使用配置中的默认端口。
3. 点击“加入房间”。客户端先建立传输连接，再校验协议版本；认证成功后服务器才生成玩家。
4. 连接成功后左上角显示连接地址；点击“退出房间并返回主菜单”可主动断开。

## 连接状态

| 状态 | 含义 |
|---|---|
| Idle | 服务已安装，尚未发起操作 |
| Starting | 正在启动 Host 或客户端传输层 |
| Connecting | 传输已启动，正在连接或进行版本认证 |
| Connected | 认证成功，可以生成玩家和进行游戏 |
| Failed | 地址错误、超时、版本不一致、房间满或被拒绝 |
| Disconnected | 主动退出或连接已关闭 |

创建或加入期间，菜单按钮和地址输入框会被锁定，以阻止重复请求。空地址、含协议头或非法端口的地址不会发起连接。

## 常见问题

- **连接超时：** 确认双方在同一局域网、房主仍在游戏中、IP 无误，并允许 UDP 7770 通过防火墙。
- **版本不一致：** 双方必须使用相同的 `protocolVersion` 和同一发布版本。
- **房间人数已满：** 等待其他玩家退出，或由开发人员调整最大人数后重新发布双方客户端。
- **房主退出：** Host 停止后所有客户端会断开；当前阶段不支持房主迁移。
- **没有房间列表：** 这是本阶段的范围约束，加入者必须手动输入房主地址。
